# API MatchHub-m2

Proyecto del Módulo 2 — Full Stack Dev Bootcamp.

## Qué es

Una API REST full-stack diseñada para organizar pachangas de Fútbol 7 que permite gestionar canchas, controlar convocatorias de jugadores en tiempo real mediante arrays dinámicos y restringir accesos según roles.

## Stack

- Node.js + Express
- MongoDB + Mongoose
- JWT para autenticación
